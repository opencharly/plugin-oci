# 2026.280.2122 — fix(oci): decode the cache wire into the single-sourced spec pair (R3)

## Summary

`candy/plugin-oci/cache_transport.go` re-declared the `verb:oci` cache-transfer wire pair as **local hand-written structs**. `spec#149` single-sourced exactly that pair in `spec/schema/oci.cue` — its own words: *"so `candy/plugin-oci`'s transport legs and `candy/plugin-cache`'s `charly cache push/pull` leaves share ONE decoded type instead of two hand-written copies that can drift"* — and `candy/plugin-cache` was migrated while this candy was not. The stated single-source was therefore only half true, and the drift was silent precisely because the two shapes are already JSON-identical.

This PR deletes the local copies and decodes/returns `spec.CacheTransferRequest` / `spec.CacheTransferReply`. **No behaviour change**: `{dir,ref,insecure?}` and `{digest?,entries?,ref?}` are the same keys in the same order on both sides.

**Files (4):** `candy/plugin-oci/cache_transport.go` (local pair deleted; the two legs + `runCachePush`/`runCachePull` use the spec types), `candy/plugin-oci/cache_transport_test.go` (same), `candy/plugin-oci/go.mod` + `go.sum` (spec pin).

Closes #7
